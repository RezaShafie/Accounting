# سیستم حسابداری پیشرفته (Accounting System)

این پروژه یک نرم‌افزار حسابداری مدرن و مقیاس‌پذیر است که با استفاده از **.NET 10**، **.NET Aspire** و معماری **Clean Architecture** توسعه داده شده است. هدف این پروژه ارائه یک راهکار قابل اعتماد برای مدیریت اسناد حسابداری با رعایت اصول دقیق مهندسی نرم‌افزار و **Domain-Driven Design (DDD)** است.

## 🚀 راهنمای اجرا (How to Run)

برای اجرای این پروژه نیاز به نصب پیش‌نیازهای زیر دارید:

### پیش‌نیازها
1.  **.NET 10 SDK**
2.  **Docker Desktop** (برای اجرای SQL Server ضروری است)
3.  **Aspire Workload**:
    ```bash
    dotnet workload update
    dotnet workload install aspire
    ```

### مراحل اجرا
1.  مخزن پروژه را کلون کنید.
2.  مطمئن شوید Docker در حال اجراست.
3.  به مسیر ریشه پروژه بروید و دستور زیر را اجرا کنید (پروژه `AppHost` نقطه شروع است):
    ```bash
    dotnet run --project Accounting.AppHost
    ```
4.  پس از اجرا، داشبورد **Aspire Dashboard** در مرورگر باز می‌شود. از طریق داشبورد می‌توانید روی لینک‌های **WebFrontend** (بخش کلاینت) یا **ApiService** (بخش سرور) کلیک کنید.

## 📖 درباره پروژه (Project Description)

این سیستم برای مدیریت چرخه حیات **اسناد حسابداری (Vouchers)** طراحی شده است. امکانات اصلی شامل ثبت، ویرایش، حذف و نهایی‌سازی اسناد، مدیریت سطرهای سند (بدهکار/بستانکار) و کنترل تراز بودن سند است.

رابط کاربری این پروژه با فریم‌ورک **Blazor** و کتابخانه کامپوننت‌های **MudBlazor** طراحی شده تا تجربه‌ای مدرن، سریع و واکنش‌گرا (Responsive) را ارائه دهد.

## 🏗 تصمیمات فنی و معماری (Technical Decisions)

در توسعه این پروژه از الگوها و تکنولوژی‌های پیشرفته‌ای استفاده شده است تا پایداری، تست‌پذیری و قابلیت نگهداری کد تضمین شود.

### ۱. معماری تمیز (Clean Architecture)
پروژه به لایه‌های مجزا تفکیک شده است تا وابستگی‌ها مدیریت شوند:
* **Domain**: قلب سیستم شامل موجودیت‌ها (`Voucher`, `VoucherLine`) و قوانین تجاری (Business Rules). هیچ وابستگی خارجی ندارد.
* **Application**: شامل Use Caseها (CQRS با کتابخانه **MediatR**).
* **Infrastructure**: پیاده‌سازی دیتابیس (EF Core)، سرویس‌های خارجی و تولید شماره سند.
* **Presentation (API/Web)**: رابط‌های کاربری و اندپوینت‌ها.

### ۲. طراحی دامنه محور (DDD)
* **Aggregate Root**: کلاس `Voucher` به عنوان ریشه تجمیع عمل می‌کند. تمام تغییرات روی سطرهای سند (`VoucherLine`) باید از طریق متدهای `Voucher` انجام شود تا یکپارچگی داده‌ها (مانند تراز بودن سند) حفظ شود.
* **Value Objects**: استفاده از `AccountCoding` برای اعتبارسنجی و فرمت‌دهی کد حساب‌ها.
* **Invariants**: قوانین اعتبارسنجی (مانند عدم امکان ثبت مبلغ منفی) درون خود موجودیت‌ها پیاده‌سازی شده‌اند.

### ۳. مدیریت همزمانی و شماره‌گذاری (Concurrency Safe Numbering)
یکی از چالش‌های اصلی سیستم‌های مالی، شماره‌گذاری سریال و بدون شکاف اسناد در محیط‌های چندکاربره است.
* **راهکار**: استفاده از یک جدول Sequence جداگانه و الگوریتم **Pessimistic Locking** (با استفاده از `UPDLOCK` در SQL Server).
* **مزیت**: این روش تضمین می‌کند که حتی اگر ۱۰۰ کاربر همزمان دکمه ثبت را بزنند، هیچ شماره سندی تکراری صادر نمی‌شود و شماره‌ها پشت سر هم خواهند بود.

### ۴. استراتژی ادغام هوشمند (Smart Merge Strategy)
در هنگام ویرایش اسناد، به جای حذف و ایجاد مجدد تمام سطرها (که باعث بهم ریختگی IDها و Fragment شدن ایندکس‌ها می‌شود)، از منطق "ادغام" استفاده شده است:
* سطرهای موجود **Update** می‌شوند.
* سطرهای جدید **Insert** می‌شوند.
* سطرهای حذف شده از لیست، **Delete** می‌شوند.

### ۵. الگوی پاکت‌نامه (Envelope Pattern / Result Pattern)
تمامی پاسخ‌های API (چه موفق و چه خطا) در یک ساختار واحد (`Result<T>`) بازگردانده می‌شوند. این کار باعث می‌شود کلاینت (Blazor) بتواند به صورت یکنواخت خطاها، پیام‌های اعتبارسنجی و داده‌ها را پردازش کند و نمایش دهد.

### ۶. تست‌های یکپارچه (Integration Tests with Testcontainers)
برای اطمینان از صحت عملکرد دیتابیس و لاجیک‌های پیچیده، از **Testcontainers** استفاده شده است.
* در هر بار اجرای تست، یک کانتینر واقعی SQL Server بالا می‌آید.
* تست‌ها روی دیتابیس واقعی اجرا می‌شوند و سپس کانتینر از بین می‌رود.
* این روش بسیار مطمئن‌تر از Mock کردن DbContext یا استفاده از دیتابیس In-Memory است.

### ۷. ارکستراسیون با .NET Aspire
پروژه با استفاده از .NET Aspire پیکربندی شده است که مزایای زیر را دارد:
* اجرای همزمان چندین پروژه (API, Web, Database) با یک دستور.
* مدیریت خودکار Connection Stringها و Service Discovery.
* داشبورد قدرتمند برای مشاهده لاگ‌ها، متریک‌ها و Traceهای توزیع شده (Distributed Tracing).
